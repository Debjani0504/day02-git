# Day 5 notes
## Data
Data is a collection of raw facts that do not have meaning by themselves.
examples: Debjani Das, 25, Kolkata.
## Information
Information is processed and organized data that has meaning.
example: Debajni is 25 years old and lives in kolkata
## Database
A database is an organized collection of related data that can be stored, managed, and accessed esily.
## DBMS
A Database Management System (DBMS) is software used to creat, store, manage, update, retrive in a database.
example:
-MySQL
-Microsoft Access
-Oracle
-PostgreSQL
## RDBMS
A Relational Database Management System (RDBMS) stores data in related tables. The tables are connected using keys, which reduces data duplication and keeps data consistent.
## SChema
A schema is the blueprint of a database. It defies the tables, columns, data types, and relationship between tables.
## Repeating Facts
Examples of repeating facts in a hospital datbase:
-Docotor name
-Department name
-Patient details
-Department locations
Why repetition is a problem:
If the same information is stored in many places, updating one record but forgetting another can lead to inconsistence and incorrect data.
